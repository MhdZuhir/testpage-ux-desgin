Desktop UX Test

This is a simple test page for my thesis project. The test is designed for desktop/laptop use. Click around, follow the tasks, and leave feedback.

Please use a desktop or laptop. The test takes about 2–4 minutes.
Start Test Leave Feedback

Test Tasks

  1. Task 1 Open the page and try to understand what it is about within 10 seconds.
  2. Task 2 Click around on buttons, links, or sections and see if anything feels unclear.
  3. Task 3 Try to find the main purpose or key feature of the page.
  4. Task 4 Scroll through the page and notice if anything is hard to find or read.

What I Want to Learn

  • Was anything confusing?
  • Was it easy to understand the purpose?
  • Was it easy to find key content?
  • Did the design feel clear on desktop?

Your interactions may be recorded (clicks, scroll, etc.) for UX analysis as part of this project.
